# Architecture Research

Research candidates are not frozen ISA/ABI contracts or approved RTL.

The original [first-principles research note](AI处理器架构_第一性原理调研与研究议程_2026-09-05.docx)
is preserved unchanged. It proposes block-structured explicit tile dataflow,
soft region affinity/local binding, distributed queues and scoped tile lifetime.
Validate the complete proposal and its components against alternatives. Its
internal suggested actions are research material, not development authority.

For each new hypothesis record the bottleneck, baseline, predicted benefit,
contract/resource changes, falsifying outcome, experiment and conclusion. The
Roadmap controls scope; accepted decisions live in Decisions. Do not create
empty framework layers for candidate mechanisms that have not been implemented.
